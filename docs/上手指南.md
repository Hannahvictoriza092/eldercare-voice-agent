## 第 1 步：配 SSH（不做这步推不上去）

国内直连 GitHub 容易失败，所以下面用 SSH 的方式。打开 PowerShell 依次执行：

```powershell
# 生成密钥（一路回车）
ssh-keygen -t ed25519 -C "你的邮箱" -f "$env:USERPROFILE\.ssh\id_ed25519" -N '""'

# 显示公钥，把输出的那一整行复制下来
Get-Content "$env:USERPROFILE\.ssh\id_ed25519.pub"
```

然后：

1. 打开 👉 https://github.com/settings/keys
2. 点 **New SSH key**
3. Title 随便填，Key type 选 **Authentication Key**
4. Key 框里粘贴刚才复制的那一行（**是 `.pub` 文件的内容，不是私钥！**）
5. 点 **Add SSH key**

验证一下：

```powershell
ssh -T git@github.com
```

看到 `Hi 你的用户名!` 就成功了。

> ❌ 报 `Permission denied` = 公钥没贴对
> ❌ 连接超时 = 看 `docs/网络与Git配置.md` 第四节的 443 端口方案

## 第 4 步：日常就这样干

```powershell
# ① 开工前先拉最新（最重要！）
git pull

# ② 写代码……

# ③ 提交前跑一下测试，全绿再提交
python -m pytest

# ④ 提交推送
git add -A
git commit -m "feat(emergency): 实现发起呼救"
git push
```

**就这 4 条命令。** 不用建分支，直接推 `main`。

### push 被拒绝了？

```
! [rejected]  main -> main (fetch first)
```

这是正常的，说明有人比你先推了。照做：

```powershell
git pull
git push
```

### 提交信息怎么写

```
<类型>(<模块>): <做了什么>
```

```powershell
git commit -m "feat(emergency): 实现发起呼救"
git commit -m "fix(health_report): 修复周报统计错误"
git commit -m "docs(emergency): 补充 README"
```

类型用：`feat`（新功能）/ `fix`（修 bug）/ `docs`（文档）。

## 附：让系统识别到自己的 skill

写完后，在自己的 `__init__.py`（比如 `skills/emergency_call/__init__.py`）里加两行：

```python
from .skill import EmergencyCallSkill
SKILL = EmergencyCallSkill()
```

然后验证：

```powershell
python -c "import skills; print(skills.all_skills()); print('跳过:', skills.skipped_packages())"
```

应该出现在 `all_skills()` 里，不该在 `跳过` 里。

> ⚠️ 注意 `SKILL = EmergencyCallSkill()` **有括号**（是实例，不是类）。
> 漏了括号会报错，报错信息里会提醒。

**没写这两行之前，这个目录会被安静跳过，不影响别人**——所以先建个空目录、慢慢写也没问题。
